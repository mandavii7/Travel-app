SDE ASSIGNMENT

Steps Followed to Complete the Assignment
•	Initialized the project structure using Vite for the frontend and Python for the backend.
•	Used Tailwind CSS for styling and configured TypeScript with proper linting.
•	Designed reusable components and pages for user-facing interfaces.
•	Built backend APIs for data persistence and retrieval using Python.
•	Connected frontend to backend using API calls for dynamic data rendering.
•	Performed local testing and debugging before finalizing the build.
Key Decisions Made During Implementation
•	Chose Vite + React for fast development and hot reloading.
•	Used Tailwind CSS for scalable, utility-first styling.
•	Opted for a simple file-based backend using Python for ease of deployment.
•	Decided on separating frontend and backend logic cleanly for modularity.
Assumptions Made
•	Assumed a local development environment for both frontend and backend (no external hosting).
•	Sample data and user scenarios were assumed for demonstration since no live API or DB was provided.
•	Authentication and user roles were considered out of scope unless specified.
Challenges Faced and How They Were Resolved
•	CORS issues while connecting frontend and backend: Resolved by enabling CORS middleware in the backend.
•	Styling consistency across components: Addressed by creating shared style classes in Tailwind.
•	TypeScript errors during integration: Fixed by ensuring all props and API responses were properly typed.
•	Backend schema mismatch: Refactored models and schemas to sync with frontend expectations.
